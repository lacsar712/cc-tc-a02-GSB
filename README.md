# 隧道收敛测缝台

测量员登记里程桩号、围岩等级（软岩/硬岩）与收敛毫米值。接口进程内后台线程认领待判行（不另起 worker 容器），按**该围岩等级认领那一刻的合格闭区间**（绝对值落入 `[下限, 上限]` mm，含端点）给出合格或超限。页面是 Svelte。

## 规则口径

- **两套闭区间，不共用门槛**：软岩、硬岩各有上下限（默认软岩 `[0, 3.0]`、硬岩 `[0, 1.5]` mm），测量员可分别设定。
- **新单必须点选等级**（`soft`=软岩、`hard`=硬岩，点选口径即入库口径）；漏选整份退回（400），不落库。
- **认领快照**：单据被领走时把该档当前上下限抄进行内快照，之后再改档，已领走的单据仍按快照判定，不翻案；待认领单据吃认领时的新区间。
- **改档履历**：每次改上下限追加一行（旧区间/新区间/改档人/时间），只增不改。
- **权限**：测量员（surveyor）可报数、可改档；巡检员（inspector）只能翻表、翻档位、翻履历，不能改档也不能报数（403）。

## 页面

页眉两个专页：

- **收敛台账**：报数表单（含围岩等级必选下拉）与全部单据，单据展示围岩档、认领快照区间、状态、结论。
- **围岩分带**：三块——上块「填档位」（软岩/硬岩上下限）、中块「改档履历」、下块「认领快照」（各已认领单据抄录的区间）。巡检员视图三块只读。

## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16（旧库启动时幂等补 `grade / snap_lower_mm / snap_upper_mm` 列）

## 接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/limits` | 登录 | 软岩/硬岩当前闭区间 |
| PUT | `/api/limits` | 测量员 | 改某档上下限，追加履历；上限不得小于下限 |
| GET | `/api/limits/history?grade=soft` | 登录 | 改档履历（可按档过滤） |
| GET | `/api/logs` | 登录 | 单据列表 |
| POST | `/api/logs` | 测量员 | 新单，必须带 `grade ∈ {soft, hard}`，漏选 400 |
